# Proxmox DEMO Lab

Учебный полигон из **15 стендов / 105 ВМ** на Proxmox VE 7. Профиль `DEMO_2` использует образы `DEMO_1`: сеть настраивают студенты. В подготовку входят дополнительные диски HQ-SRV, `Additional.iso`, APT-прокси и исходные снимки `Day0`.

Основа — [ИТ-СПЕЦНАЗ / proxmox-auto-deploy](https://github.com/elena777-int/proxmox-auto-deploy), лицензия MIT. Здесь закреплены исходники, собраны наши исправления и инструкция конкретного полигона.

## С чего начать

- **Стенды уже работают:** [эксплуатация](docs/OPERATIONS.md). Повторный деплой и финализация не нужны.
- **Установка с нуля:** [пошаговая инструкция](INSTALL.md).
- **Печатная памятка:** [хендбук PDF, 9 страниц](docs/handbook-demo2.pdf).
- **Что изменили:** [патчи и происхождение](docs/PATCHES.md).
- **Откуда 5115 ГиБ:** [расчёт ёмкости](docs/CAPACITY.md).

## Конфигурация профиля

| Параметр | Значение |
| --- | --- |
| Хост | `pve`, Proxmox VE 7 / Debian 11 |
| WAN | `vmbr0`; хост `10.0.55.12/24`, шлюз `10.0.55.1` |
| Пулы | `DEMO_2_S1` … `DEMO_2_S15` |
| VMID | `20000 + (номер стенда − 1) × 100 + номер роли` |
| Рабочие диски | `ssd`, тип `dir`, `/mnt/ssd`, формат QCOW2 |
| Архивы | `/mnt/pve/VM_Disk/spetsnaz-images/DEMO_1` |
| ISO | `local:iso/Additional.iso`, метка тома `Additional` |
| Кэшер | `apt-cacher-ng`, `10.0.55.12:3142` |
| Данные кэша | `/mnt/pve/VM_Disk/apt-cache` |
| Каталог установки | `/root/proxmox-auto-deploy` |

Это профиль конкретного сервера. Финализатор проверяет эти адреса, имена, пути и VMID. Для другой инфраструктуры требуется согласованно изменить конфигурацию, проверки и документацию. Установочные команды не форматируют физические накопители.

## Состав стенда

| Окончание VMID | Роль | Среда |
| --- | --- | --- |
| 01 | ISP | Альт Linux |
| 02 | HQ-RTR | EcoRouter |
| 03 | BR-RTR | EcoRouter |
| 04 | BR-FW | Ideco |
| 05 | HQ-SRV | Альт Linux; основной диск и два пустых по 1 ГиБ |
| 06 | HQ-CLI | Альт Linux |
| 07 | BR-SRV | Альт Linux |

`Additional.iso` подключается к HQ-SRV и BR-SRV и монтируется в `/mnt/additional` только для чтения. RAID и файловую систему на дополнительных дисках создаёт студент. На внутренних ВМ доступ к кэшеру появится после настройки учебной сети.

## Файлы проекта

| Файл / каталог | Назначение |
| --- | --- |
| `core.sh`, `menu.sh` | Оркестратор с нашим профилем |
| `scripts/prepare_disks.py` | Конвертация RAW → QCOW2, сравнение данных и удаление только проверенного исходника |
| `finalize_demo2.py` | Разовая подготовка 15 стендов, до двух одновременно |
| `repair_alt_apt.py` | Исторический ремонт прерванной подготовки; при новой установке не нужен |
| `scripts/preflight_install.py` | Проверки перед новым деплоем без изменения ВМ |
| `scripts/audit_demo2.py` | Чтение состава готовых стендов, дисков, ISO и Day0 |
| `config/` | Примеры конфигурации без паролей |
| `patches/`, `vendor/upstream/`, `UPSTREAM.json` | Патч, оригиналы и контрольные суммы |
| `tests/` | Модели команд Proxmox и проверки гостевых команд |
| `docs/` | Инструкции и готовый PDF |

Образы `.vma.zst`, ISO, рабочие диски, пароли, `credentials/`, журналы и файлы состояния **не включены**. Образы и Additional.iso нужно получить самостоятельно из разрешённых учебных источников.

## Проверки и границы

Локально проверены Bash/Python-синтаксис, воспроизводимость патча и моделируемые операции: выбор VMID, ошибки восстановления, 15 стендов с двумя исполнителями, гостевые агенты, APT, автомонтирование, проверки QCOW2 и создание снимков. Команды — в [PATCHES.md](docs/PATCHES.md).

Полная новая установка опубликованной сборки на отдельном Proxmox пока не выполнялась. На действующем сервере диски конвертировали после восстановления. Здесь добавлен новый воспроизводимый помощник конвертации: он проверен на моделях команд, но ещё не запускался на живом Proxmox. Точной копии всех живых файлов сервера здесь нет: профиль восстановлен из закреплённого upstream и известных правок. Публикация не обновляет сервер.

Хендбук фиксирует состояние на 03.11.2026. Для новой установки используйте `INSTALL.md`: там описаны команды опубликованного помощника конвертации.
