# Дисковая ёмкость

Число **5115** получено как **341 × 15**. Это виртуальная ёмкость, видимая гостям, а не уже занятое место.

| Роль | Объявленная ёмкость, ГиБ |
| --- | ---: |
| ISP | 40 |
| HQ-RTR | 6 |
| BR-RTR | 6 |
| BR-FW | 167 |
| HQ-SRV | 40 + 1 + 1 = 42 |
| HQ-CLI | 40 |
| BR-SRV | 40 |
| **Один стенд** | **341** |
| **15 стендов** | **5115** |

Маленькие EFI/cloud-init тома добавляют незначительный объём к округлённой оценке. Исходный скрипт делит байты на 1024³ и подписывает «ГБ»; технически это **ГиБ**. 5115 ГиБ — около 5,0 ТиБ виртуальной ёмкости.

При подготовке данные занимали около 26,7 ГиБ на стенд, или около 401 ГиБ на 15. QCOW2 растёт при записи, снимки тоже расходуют место. SSD около 2,3 ТиБ хватает для исходного наполнения, но не для полного заполнения всех виртуальных дисков.

Проверяйте реальное место через `df -h /mnt/ssd` и меню «Место, занятое стендами». Сохраняйте запас около 20%. Исторический замер в хендбуке не является текущим мониторингом.
